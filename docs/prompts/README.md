# Prompts

Every prompt given to Claude Code is saved here, so the history of what was asked stays
in the repo.

- File name: `NNN-short-name.md` (e.g. `001-product-research.md`).
- A follow-up fix uses the same number: `001-product-research-fix.md`.
- The matching report goes to `../reports/NNN-short-name.md`.
