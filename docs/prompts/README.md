# Prompts

Every prompt given to Claude Code is saved here in full, so the history of what was asked
stays in the repo. Claude Code saves the prompt at the start of each task, in English
(translated if the user wrote it in another language).

- File name: `NNN-short-name.md` (e.g. `001-product-research.md`). Claude Code assigns
  `NNN` sequentially (next free number).
- Every new round of the same task, fixes included, gets the next version suffix:
  `001-product-research-v2.md`, `001-product-research-v3.md`, …
- The matching report carries the same name in `../reports/` (e.g.
  `../reports/001-product-research-v2.md`).
